# YarnJolt

Watches and aggregates cryptocurrency market data from multiple exchanges and APIs for real-time price tracking.

The key benefits of using YarnJolt include:

- Watches and aggregates cryptocurrency market
- data from multiple exchanges and
- APIs for real-time price tracking

- Watches and aggregates cryptocurrency market

- APIs for real-time price tracking

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/YarnJolt.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

YarnJolt is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
